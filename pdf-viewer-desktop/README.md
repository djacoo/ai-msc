# AI Masters PDF Viewer

Desktop app for viewing course PDFs with AI assistance.

## Quick Start

```bash
npm install
npm start
```

## Build

```bash
# Quick rebuild and install
./quick-update.sh

# Full build with details
./build-and-install.sh
```

## Requirements

- Node.js
- Ollama (for AI chat)

## Controls

- `←` `→` - Navigate pages
- `+` `-` - Zoom
- Click TOC icon for table of contents
- Type page number in search to jump
