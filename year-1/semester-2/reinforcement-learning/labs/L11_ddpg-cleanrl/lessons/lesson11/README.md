# RL-Laboratory🤖 DDPG CleanRL Laboratory

This repository contains a Deep Deterministic Policy Gradient (DDPG) laboratory based on the [CleanRL](https://github.com/vwxyzjn/cleanrl) framework. DDPG is specifically designed for environments with continuous action spaces.

The folder includes:
- `lesson11_cleanRL_ddpg_train_code.py`: The template file for students with `# TODO` sections for implementing the Critic, Actor, and loss updates.
- `lesson11_cleanRL_test.py`: A script to load and render the trained policy.

## Prerequisites

We recommend using **Python 3.10** or **Python 3.11**.
- On Windows, the command is usually `python` or `py`.
- On Unix/Linux/macOS, the command is usually `python3`.

## Setup Instructions

Please create a virtual environment to isolate the project dependencies. Ensure you use the provided `requirements.txt` file (the same as in the PPO laboratory).

### Windows

1. Create the virtual environment:
   ```powershell
   python -m venv .venv
   ```
2. Activate the virtual environment:
   ```powershell
   .\.venv\Scripts\activate
   ```
   *(Note: if PowerShell blocks the execution, you might need to run `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` first).*
3. Install dependencies:
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

### Unix / Linux / macOS

1. Create the virtual environment:
   ```bash
   python3 -m venv .venv
   ```
2. Activate the virtual environment:
   ```bash
   source .venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   python3 -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

## Running the Training

You can train the agents on multiple environments defined in the repository scripts. The scripts will automatically loop through the environments and save the models (and learning curves) in the `models/` directory or output plots in the root directory.

### Windows
Run the batch script:
```powershell
.\lesson11_cleanRL_run_train.bat
```

### Unix / Linux / macOS
Make the script executable and run it:
```bash
chmod +x lesson11_cleanRL_run_train.sh
./lesson11_cleanRL_run_train.sh
```

*(Optional) You can also run the training manually for a single environment:*
```bash
python lesson11_cleanRL_ddpg_train_code.py --env-id Pendulum-v1 --total-timesteps 50000
```

**Note**: DDPG only works on environments with **continuous** action spaces (e.g., `Pendulum-v1`, `MountainCarContinuous-v0`, `BipedalWalker-v3`). It will fail if run on discrete environments like `CartPole-v1`.

## Running the Tests

Once the training is complete, an output model file (e.g., `ddpg_Pendulum-v1_actor.pth`) is generated inside the `models/` directory.

To test and visually render the agent, use the `lesson11_cleanRL_test.py` script. Simply execute the following commands in your terminal (ensure your virtual environment is still active):

```bash
python lesson11_cleanRL_test.py --env-id "Pendulum-v1" --model-path "models/ddpg_Pendulum-v1_actor.pth"
```

*Important: Make sure to replace the dummy paths in the `.bat` and `.sh` files with the actual path generated by your training job before running `lesson11_cleanRL_run_test.bat` or  `lesson11_cleanRL_run_test.sh`.*

# DDPG Training Guide: Environment-Specific Setups

**Note**: DDPG is an off-policy algorithm that relies heavily on a Replay Buffer. It requires exploration noise (Gaussian or Ornstein-Uhlenbeck) since the policy is deterministic.

Below is a practical guide for training various continuous Gymnasium environments.

---

## 1. Pendulum-v1 (Continuous)
* **Challenge:** The classic continuous control benchmark. The agent must balance a pendulum using precise torque.
* **Setup Suggestion:** Default DDPG hyperparameters generally work well here. Focus on learning rate and soft update coefficient (`tau`).
```bash
    python lesson11_cleanRL_ddpg_train_code.py --env-id Pendulum-v1 --total-timesteps 50000
```

## 2. MountainCarContinuous-v0 (Continuous)
* **Challenge:** **Severe Sparse Rewards.** The agent gets penalised for moving but receives a large reward for reaching the flag. DDPG's default uniform or Gaussian noise may struggle to push the car far enough up the hill purely by chance.
* **Setup Suggestion:** Requires significantly more steps and larger exploration noise initially. *(Note: If standard training fails, Reward Shaping is often strictly necessary for this environment).*
```bash
    python lesson11_cleanRL_ddpg_train_code.py --env-id MountainCarContinuous-v0 --total-timesteps 300000 --exploration-noise 0.2
```

## 3. BipedalWalker-v3 (Continuous)
* **Challenge:** Highly complex dynamics, a high-dimensional observation space (24 observations) and 4 continuous actions. The agent must learn a coordinated walking gait.
* **Setup Suggestion:** Requires millions of steps and a very large replay buffer (default $10^6$ is good, but memory intensive). Training this locally without a GPU might take a considerable amount of time.
```bash
    python lesson11_cleanRL_ddpg_train_code.py --env-id BipedalWalker-v3 --total-timesteps 1000000 --learning-rate 3e-4 --batch-size 256
```
